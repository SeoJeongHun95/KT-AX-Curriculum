# grilling — 자기 말로 설명하고 질문받기

주제: $ARGUMENTS

## 진행 순서

1. 사용자에게 다음 문장으로 시작합니다. 「<주제>를 처음 배우는 사람에게 설명한다고 생각하고, 자기 말로 써 주세요. 교재를 보지 않고 씁니다.」 사용자의 설명이 올 때까지 기다립니다.
2. 설명을 받으면 다음 세 가지를 찾습니다. 찾은 것을 사용자에게 말하지 않고 질문으로만 바꿉니다.
   - 빈 곳: 설명에서 건너뛴 단계
   - 어긋난 곳: 사실과 다른 문장
   - 흐린 곳: 뜻을 정하지 않고 쓴 용어
3. 질문은 한 번에 하나만 합니다. 질문은 「왜 그렇게 되는가」 「그러면 어떤 일이 생기는가」 「그 용어는 무엇을 뜻하는가」 중 하나의 형태로 합니다.
4. 사용자의 답을 받고 3을 반복합니다. 반복은 세 번에서 다섯 번 사이입니다.
5. 마무리에서 다음 세 가지를 목록으로 적습니다.
   - 사용자가 정확히 설명한 것
   - 사용자가 설명하지 못한 것 (항목 이름만 적고 내용은 적지 않습니다)
   - 다시 볼 곳 (교재의 절 이름 또는 실습 파일 이름)

## 규칙

- 정답을 말하지 않습니다. 사용자가 정답을 두 번 요구하면 그때 정답을 요약하고, 정답과 사용자 설명의 차이를 함께 적습니다.
- 사용자의 설명을 칭찬으로 시작하지 않습니다. 첫 문장은 질문입니다.
- 비유로 되묻지 않습니다. 실제 예시와 실제 값으로 되묻습니다.

## 하지 않을 일

- 사용자가 설명하기 전에 주제를 먼저 설명하지 않습니다.
- 한 번에 여러 질문을 던지지 않습니다.
- 사용자의 파일을 만들거나 고치지 않습니다. 이 스킬은 대화만 합니다.
