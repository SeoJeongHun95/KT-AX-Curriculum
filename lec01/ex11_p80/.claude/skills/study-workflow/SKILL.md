# 학습 도우미 워크플로우

<!-- 여기에 이 스킬이 소유하는 순서 전체를 한 줄로 설명합니다. -->
사용자의 학습질문 하나를 5단계로 처리합니다.
각단계가 진행되어 다음 단계에 진입할때 현재 단계를 출력한다.

## 1단계 — 질문 구체화

<!-- 여기에 누가 이 단계를 맡는지, 무엇을 되묻는지, 이 단계의 결과물이 무엇인지 씁니다. -->
- 메인 에이전트가 직접수행합니다.
- 질문을받아 관련된 주제에대한 세부사항을 되묻습니다.
- 단 이미 고도화된 주제라 생각되면 해당 단계는 스킵합니다.
- 이단계의 결과물 : 고도화된 주제.

## 2단계 — 조사

<!-- 여기에 어느 서브에이전트를 부르는지, 무엇을 전달하고 무엇을 돌려받는지 씁니다. -->
- `researcher`서브 에이전트를 호출합니다.
- 전달할것 : 구체화된 질문, 사용자의 현재 수준, `wiki/` 폴더 위치.
- 받을것 : 구체화된 질문에대한 자료 조사결과.
- 자료 조사결과가 없을경우 최초로 돌아가 다시 질문을 구체화한다.

## 3단계 — 1차 답변 생성

<!-- 여기에 어느 서브에이전트를 부르는지, 무엇을 전달하고 무엇을 돌려받는지 씁니다. -->
- `drafter`서브 에이전트를 호출합니다.
- 전달할것 : 구체화된 질문에대한 자료 조사결과.
- 받을것 : 고도화된 질문에대한 자료 조사 결과를 바탕으로 100자 이내의 간결한 답변.

## 4단계 — 적절성 검토

<!-- 여기에 어느 서브에이전트를 부르는지, 판정 결과에 따라 어디로 되돌아가는지 씁니다. -->
- `reviewer`서브 에이전트를 호출합니다.
- 전달할것 : 고도화된 질문에대한 자료 조사 결과를 바탕으로 100자 이내의 간결한 답변.
- 전달받은 자료에대한 사실여부를 판단합니다. 
- 사실여부가 확인되지 않거나 틀리다면 3단계 조사단계로 돌아갑니다. 


## 5단계 — 통합과 문서화 (메인 에이전트가 직접 답하고, 노트 저장만 임시 서브에이전트에 병렬로 맡깁니다)

<!-- 여기에 최종 답변을 어떻게 전달하는지, 학습 노트를 어디에 어떤 이름으로 저장하는지 씁니다.
여기에 저장 직후 훅이 무엇을 하는지(규격 검사와 목록 갱신), 스킬이 훅을 부르지 않는 이유, 훅이 규격 위반을 돌려주면 어떻게 하는지를 씁니다. -->
- 메인 에이전트가 최종 답변을 채팅으로 사용자에게 전달합니다.
- 답변을 전달하는 것과 동시에, 메인 에이전트는 학습 노트 저장을 임시 서브에이전트에게 「이 내용을 노트로 저장해」라고 맡깁니다. 저장 담당 서브에이전트는 별도 문서(`.claude/agents/`)가 없습니다. 위 3종(researcher·drafter·reviewer)은 노트 저장과 무관합니다.
  - 저장 위치: `wiki/` 폴더
  - 파일 이름: `YYYY-MM-DD_주제.md`
  - 포함할 항목: 질문, 자료, 요약, 답변, 다음에 스스로 확인해 볼 것
- 저장이 끝나면 메인 에이전트가 저장한 파일 경로를 사용자에게 알립니다.
- 저장 직후 훅(`.claude/settings.json`의 PostToolUse · Write·Edit · 조건 `wiki/*.md`)이 `update_index.py`를 실행해 노트 규격을 검사하고 `wiki/INDEX.md`를 갱신합니다. 이 스킬은 훅을 부르지 않습니다. 훅은 `wiki/`에 학습 노트가 저장될 때만 스스로 돕고, 다른 파일을 쓸 때는 돌지 않습니다. 훅이 규격 위반을 돌려주면 그 이유대로 노트를 고쳐 다시 저장합니다.


## 완료 확인

<!-- 여기에 워크플로우가 끝났을 때 무엇을 보고할지 씁니다. -->
- 5단계가 모두 끝나면 다음 세 가지를 한 줄씩 보고합니다.
  - 호출한 서브에이전트 이름 들
  - 저장한 학습 노트 경로
  - 4단계 판정 결과

## 하지 않을 일

<!-- 여기에 이 순서를 어길 때 생기는 일을 막는 금지 사항을 씁니다. 학습 노트를 어디 밖에 저장하지 않는지, 이전 노트를 지우거나 덮어쓰지 않는다는 것, INDEX.md를 직접 고치지 않는다는 것을 포함합니다. -->

- 서브에이전트가 할 일을 메인 에이전트가 대신하지 않습니다.
- 학습 노트를 `wiki/` 폴더 밖에 저장하지 않습니다.
- 이전 학습 노트를 지우거나 덮어쓰지 않습니다. 새 파일로 만듭니다. `wiki/INDEX.md`는 훅이 만드는 목록이라 직접 고치지 않습니다.
