# eli5 — 처음 듣는 사람에게 설명하기

주제: $ARGUMENTS

## 만드는 것

- `wiki/eli5_<주제>.html` 파일을 만듭니다. `wiki/` 폴더가 없으면 만듭니다.
- 파일은 그림이 중심이고 글자는 적습니다. 그림은 인라인 SVG로 그립니다. 외부 이미지 링크를 쓰지 않습니다.
- 그림마다 제목과 설명 문장을 붙입니다. 설명 문장은 그림 하나에 두 문장 이하로 합니다.

## 그림 규칙

- 정확한 기술 용어를 씁니다. 비유를 쓰지 않습니다.
- 주어와 목적어가 있는 완전한 문장을 씁니다. 대명사로 끝내지 않습니다.
- 그림 하나에 개념 하나만 담습니다.
- 흐름의 방향은 하나입니다. 왼쪽에서 오른쪽, 또는 위에서 아래 중 하나를 고릅니다.
- 그림 하나의 상자는 7개 이하입니다.
- 모든 화살표에 그 화살표가 뜻하는 것을 라벨로 적습니다.

## 학습 규칙 (학습 도우미 지침과 같습니다)

- 파일 끝에 「스스로 확인할 질문」 두 개를 적습니다. 질문의 답은 파일에 적지 않습니다.
- 파일을 만든 뒤 사용자에게 파일 경로를 알리고, 그림 중 하나를 골라 「이 화살표가 무엇을 뜻하는지 설명해 보세요」라고 묻습니다.

## 하지 않을 일

- 주제와 무관한 배경 설명을 덧붙이지 않습니다.
- 사용자가 요청하지 않은 파일을 고치지 않습니다.
